# LocalScribe

Локальное приложение для Apple Silicon: Tauri 2, React, AVFoundation, Python/MLX Whisper и SQLite. Модель `mlx-community/whisper-large-v2-mlx` включается в сборку; распознавание выполняется на устройстве без облачного API. Записи, копии импортированных файлов и база находятся в `~/Library/Application Support/LocalScribe`.

## Сборка

Требуются macOS 15 или новее на Apple Silicon, Xcode Command Line Tools, Node.js, Rust/Cargo и Python 3.9 или новее. На этапе подготовки нужны интернет и несколько гигабайт свободного места для модели и зависимостей; во время распознавания сеть не используется.

```sh
./scripts/prepare.sh
npm install
npm run tauri build
```

Готовый пакет создаётся в `src-tauri/target/release/bundle/macos/LocalScribe.app`. Скрипт собирает нативный рекордер, Python-сервис и статический FFmpeg, а также скачивает модель. Для разработки можно запустить `npm run tauri dev` после подготовки ресурсов. Если Cargo установлен вне PATH, добавьте его в PATH перед сборкой.

После завершения записи транскрибация запускается отдельной кнопкой; автоматический запуск выключен по умолчанию. Наблюдаемая папка проверяется каждые 10 секунд: файлы, не менявшиеся последние 10 секунд, копируются в библиотеку и ставятся в очередь. При аварийном завершении задания помечаются ошибкой и могут быть запущены заново. Исходные файлы не удаляются при ошибке распознавания.

## Проверки и ограничения

На M5 проверены сборка `.app`, импорт, воспроизведение и локальная транскрибация короткого тестового аудио, а также запись с микрофона через интерфейс с паузой, продолжением и воспроизведением. Подпись разработчика, notarization, установка на чистый Mac, длительные записи и восстановление после прерывания аудиоустройства пока не проверены. Используйте резервную запись для важных встреч до завершения этих проверок.

```sh
PYTHONPYCACHEPREFIX=/tmp/localscribe-pycache python3 -m unittest discover -s tests -v
CLANG_MODULE_CACHE_PATH=/tmp/localscribe-clang-cache swiftc native/Recorder.swift -o /tmp/localscribe-recorder
```

Для HTTP-тестов нужен доступ к loopback. Использованная для сборки модель MLX требует macOS 15 или новее.
